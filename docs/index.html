Case for Action
Business Case
The Problem
Marketing campaigns require simultaneous coordination across content, web, analytics, and communication. A single AI agent — or a single human — cannot reliably orchestrate all dimensions at once without sacrificing quality, speed, or visibility.
The Solution
Specialised agents each own one domain. An Orchestrator routes work in parallel, humans retain oversight at every channel, and all deliverables are surfaced automatically — as documents, websites, and an email summary — without manual coordination.

Design Principle
Human in the Loop
Synergy keeps humans visible at every meaningful touchpoint — as the initiator, as an observer on Discord, and as the final recipient — without requiring manual coordination between stages.
Control Points
01
User Initiates
A human submits a marketing brief via n8n chat. User intent and tone set the direction for every downstream agent. The human defines the goal — the system does the work.
02
Discord as Control Surface
n8n-bot posts build instructions to a designated channel. Humans can observe, pause, or redirect the thread at any point before Hermes executes. The channel is always auditable.
03
Delivery & Validation
The Orchestrator compiles all output URLs — Google Docs, two GitHub Pages sites — into an HTML email sent to the requester. The human validates and iterates by re-submitting a refined prompt.
04
Iterative Refinement
The entire pipeline is idempotent. Repositories are updated on re-runs, not recreated. Users can improve outputs incrementally without resetting state.

Architecture Concept
Harness Engineering
Synergy is built as a harness — a structured connective layer that wires specialised tools, agents, and APIs into a coherent, observable pipeline with defined boundaries and explicit data contracts.
Orchestration
n8n Runtime
Each JSON workflow is an independent, testable unit. Outputs pass between workflows via structured JSON contracts — no implicit shared state.

Purpose & Impact
Learning Outcomes
Synergy Marketing Ecosystem is designed as a teachable system. Every component is intentionally observable, replaceable, and documented — built for hands-on laboratory exercises.
AI Agent Architecture
  • Decompose complex tasks across specialised, single-responsibility agents
  • Understand how orchestrators coordinate parallel sub-workflows
  • Apply structured JSON contracts between agent boundaries
  • Explore LLM inference with Ollama for local and cloud contexts
Integration Engineering
  • Integrate Google Workspace APIs via OAuth 2.0 (Mail, Drive, Docs)
  • Set up and manage Discord bots with privileged gateway intents
  • Authenticate GitHub CLI and publish sites via GitHub Pages
  • Configure environment variables and n8n credential stores securely
Human-in-the-Loop Design
  • Design AI systems that keep humans in control at critical checkpoints
  • Use Discord as a live, auditable control surface for agent observation
  • Build delivery mechanisms that surface outputs to stakeholders
  • Implement iterative refinement loops via chat re-submission
Harness Engineering
  • Build modular workflow components with clear input/output boundaries
  • Understand bot-to-bot communication patterns across platforms
  • Apply security best practices for tokens, OAuth, and PATs
  • Deploy multi-environment systems spanning cloud and local hosts
